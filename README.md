# Android Course Rating App

The source code of a Android coursework project for CS124: Intro to Computer Science at the University of Illinois Urbana-Champaign, Fall 2023.

## Features Represented

- Course browsing, search, and list display.
- Course details and descriptions.
- Viewing and submitting course ratings.

## Source Files

The archive includes Java classes for activities, course and rating models, list adapters, application setup, and shared helpers.
